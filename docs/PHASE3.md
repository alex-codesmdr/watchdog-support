## Decisions

- **ADR-022** Local storage uses SeaweedFS because MinIO stopped publishing images; production can use any S3 API.
- **ADR-023** Knowledge-base search runs in PostgreSQL (amends ADR-007), with measured evidence; OpenSearch remains an adapter option.
- The SLA monitor relies on a 30-second check rather than per-clock timers. Alerts can be up to 30 seconds late, which is acceptable against 15-minute targets and simpler to operate.
- Spreadsheet import never moves a serial number between customers; that is a transfer/RMA decision made by a person.
- Import dates accept ISO (2026-01-31) and Indian day-first (31/01/2026); ambiguous US month-first is not accepted.
- First sign-in account linking is serialised per identity (migration 0007) after a CI run showed concurrent first requests returning "not provisioned".
- Release files are scanned like case attachments; an infected file can never be published or downloaded.
- Download access is decided per request in the API and enforced again by row-level security (internal and draft releases are invisible to customer sessions).
- Articles drafted from cases start **internal** and carry a reminder to remove customer details before publishing.
